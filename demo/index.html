cavalier//contours

2-D polyline offset & boolean — pure TS port

Using the library

Pure TypeScript, zero runtime dependencies. Runs in the browser, a worker, or Node. Install from npm: 

npm install cavalier-contours-js
import { plineClosed }
  from "cavalier-contours-js";

// x, y, bulge  (bulge 1 = half-circle)
const pl = plineClosed([
  [0, 0, 0], [10, 0, 1],
  [10, 5, 0], [0, 5, 1],
]);

pl.parallelOffset(1);    // -> Polyline[]
pl.boolean(other, "or"); // or|and|not|xor
